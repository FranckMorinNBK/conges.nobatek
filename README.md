# Suivi Congés

Calendrier de suivi des congés — CP, RTT, jours OFF, CET, maladie — en une seule page.

**→ [Ouvrir l'application](https://franckmorinnbk.github.io/conges.nobatek/)**

## Première utilisation

1. Cliquez sur **Nouveau fichier** et enregistrez `suivi-conges.json` où vous voulez (Documents, OneDrive…).
2. Posez vos congés : clic pour une journée, glisser pour une série, clic droit pour effacer.

Tout est écrit dans votre fichier au fur et à mesure. Il n'y a rien à enregistrer.

Vous avez déjà un fichier de suivi ? Prenez **Ouvrir mon fichier** plutôt que « Nouveau fichier ».

## Les fois suivantes

Ouvrez la même adresse : vos congés sont là. Si le navigateur redemande l'accès au fichier, un clic sur **Reprendre** suffit — et cochez « Autoriser à chaque visite » s'il vous le propose.

## À savoir

- Chrome ou Edge : Firefox et Safari ne savent pas écrire un fichier local.
- Votre fichier reste sur votre ordinateur ; rien n'est envoyé nulle part.
- Pour sauvegarder ou emporter votre suivi, copiez ce fichier.
